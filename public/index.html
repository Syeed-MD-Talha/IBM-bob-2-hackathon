⚙ How it works

      
    
        
  1. PDF → PPTX: each PDF page is rendered to an image (PDF.js) and placed full-bleed on its own slide (PptxGenJS). Layout is pixel-faithful; slides are images, not editable text.
    2. 
        
  2. PPTX → PDF: the .pptx (a ZIP of XML) is unzipped in-browser (JSZip); slide text + images are extracted in presentation order and rebuilt as a clean PDF (jsPDF).
    3. 
        
  3. Nothing uploads anywhere. Open DevTools → Network while converting: zero file traffic. That is why it runs on Vercel free forever.
    4. 
      

    

    

      
⚠ Honest limits (Option A)

      
    
        
  • Only modern .pptx — old binary .ppt is not supported.
    • 
        
  • PPTX → PDF keeps text + images, but not exact fonts, animations, transitions, charts, SmartArt or embedded video.
    • 
        
  • PDF → PPTX slides look identical but are images — text isn't selectable/editable.
    • 
        
  • Password-protected PDFs are rejected. Very large files (>100MB) may exhaust browser memory.
    • 
        
  • Need pixel-perfect editable output? That's Option B/C (paid API or LibreOffice backend) — not possible on Vercel free.
